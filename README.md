# Heart Rate Monitoring and Fall Detection System for Seniors

Arduino-based embedded system developed as a first-year university project.

## Features
- Heart rate monitoring
- Fall detection
- Warning/alert functionality
- Real-time sensor data processing

## Hardware
- Arduino
- Heart rate sensor
- Motion/fall detection sensor
- Buzzer / LED

## Technologies
- Arduino
- C/C++
- Embedded systems
- Sensor data processing
